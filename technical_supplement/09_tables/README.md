# Table Index

All tables are generated by `analysis/scripts/make_tables.py` and written
to `analysis/tables/` as LaTeX fragments that the paper `\input`s. None is
hand-written, so none can drift from the data.

## In the paper

| Paper number | File | Function | Reads |
| --- | --- | --- | --- |
| Table 1 | `In paper/t3_mechanism.tex` | `t3_mechanism` | `a7_mechanism.json` |
| Table 2 | `In paper/t7_master.tex` | `t7_master` | all three study CSVs via `load_all` |
| Table 3 | `In paper/t2_frontier.tex` | `t2_frontier` | `a6_at_the_frontier.json` |
| Table 4 | `In paper/t1_regime.tex` | `t1_regime` | `a3_component_regime.json` |
| Table 5 | `In paper/t9_comparison.tex` | `t9_comparison` | study CSVs plus `e3_thinet.csv` |
| Table 6 | `In paper/t5_attention.tex` | `t5_attention` | `compression_transformer/results/attention.csv` |

Table 2 is the master table: every checkpoint at its own operating point, with
parameter and MAC reduction and four paired contrast columns. It is the table to
read if the question is whether the effect is carried by a subset of models. It
is not: the repair column is positive on all 24 rows where both members ran.

## Reproducing them

```
cd analysis/scripts
python3 make_tables.py
```

This also writes `results/paper_numbers.json`, a single consolidated record of
every headline figure in the paper. That file is the fastest way to check the
paper's arithmetic without rerunning anything: each field corresponds to a number
quoted in the text, and `../CLAIM_TO_EVIDENCE.md` maps them.
